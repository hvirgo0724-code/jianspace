## 1. AI 装修流程

- 生成前明确选择一个房间，只能选最多两张与该房间关联的照片。
- 后端按本次场景快照绘制 1024×1024 实测平面参考，显示宽、深、高、门窗及家具；参考预览在未确认草稿中也可检查。
- 真正提交生图要求确认尺寸来源、服务端启用和可用积分；真实房屋选用户实测，流程体验可明确选虚构演示。请求发送尺寸参考、照片或 3D 来源及结构文字。总图像数不超过三张，最后一张参考决定视角底图与输出比例参考。
- 生成结果保存结构哈希、家具布局哈希、房间参数与来源照片 ID；不会把效果图反写成实测几何。
- 在“房间照片”中的生成结果上点击“核对结构与比例”，并排查看源照片、生成时的实测参考和 AI 结果，对墙、门、窗、家具、比例记录“一致 / 差异 / 不确定”。
- 全部人工判断一致且无自动高风险时可显示已复核；自动/人工差异、当前几何或家具布置变化要求调整；存在不确定项时保持待复核。此记录不等于像素级几何保证或施工验收。

接口按[阿里云千问图像编辑官方文档](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)核对，未自行假设支持严格几何控制。当前采用图片与文字引导，模型仍可能改变门窗或比例，真实效果必须验收。

本地配置文件为项目根目录 `.env`，不要把密钥发送到聊天或写进前端代码：

```dotenv
DASHSCOPE_API_KEY=填写你自己的服务端密钥
ALLOW_AI_CALLS=true
DASHSCOPE_IMAGE_MODEL=qwen-image-2.0-pro
DASHSCOPE_API_BASE=https://dashscope.aliyuncs.com
```

模型、地域、业务空间域名须与实际账户匹配。配置后重启 API，真实房屋上传照片并确认实际尺寸，再确认积分上限生成；演示流程使用单独的来源声明和明确非实拍素材。测试工程量与模板均为虚构数据，没有伪造“已确认实测”。

可运行 `python scripts/check_ai_config.py` 检查配置是否存在并启用；此脚本不打印密钥、不调用服务商、不产生费用。

模型、地域与自动备用切换的配置详见 [AI_MODEL_CONFIGURATION.md](AI_MODEL_CONFIGURATION.md)。新增 `DASHSCOPE_IMAGE_FALLBACK_MODELS`，按顺序在明确额度耗尽或限流时尝试同地域的备用图像编辑模型；超时或鉴权失败不会触发自动重生图。

新增自动测试使用 HTTP 响应夹具和明确的 `testFixture` 元数据，覆盖请求中的参考图和尺寸、任务执行、来源快照、待复核/差异记录及参考读取，未连接收费服务。浏览器上传验证使用 `合成3D参考（非实拍）.png`，不是毛坯实拍照片。

## 2. 日常编辑与结构参数

| 功能 | 操作与行为 |
| --- | --- |
| 多选 | Shift 点选，或启用“多选”后逐件点选；对象列表也可选择 |
| 整组移动 | 拖动组内任一选中家具，或填写 ΔX/ΔY；锁定项跳过 |
| 复制 | 工具栏“复制”或 Ctrl/Cmd+D；保留造型、尺寸、报价，创建独立目录快照，尝试在房间内避开已有家具 |
| 对齐 | 左/右/水平居中、上/下/垂直居中；根据旋转后的外接边界处理 |
| 快捷操作 | Delete 移除未锁定选中物品；方向键移动 50 mm，Shift+方向键移动 10 mm；输入框和漫游区域不拦截这些键 |
| 画布平移 | 点击“平移”拖动画布；“适应”复位。视图平移不改场景、不产生保存或历史记录 |
| 距离参考 | 单选家具时显示至矩形房间净边界的四向距离；旋转家具按外接边界计算，非矩形房间不显示该简化标注 |
| 墙体联动 | 可改墙厚、墙高、中心线端点；连接墙端点同步移动，房间角点按新墙内表面交点重建，净面积同步计算 |
| 楼层标高 | “楼层与楼梯参数”面板填写本层标高并应用 |
| 直跑楼梯 | 调整起点、终点、宽度、踏步数、目标楼层，也可添加或移除参考梯段；参数更新后校验平台位置和区域冲突 |

对齐、移动和复制后仍要运行场景校验，不能将“有空间放下”当成通行或安装合格。任意 CAD 墙网自动修复、连续走上台阶、任意楼板洞口编辑不在本轮已完成范围。

## 3. 布局与装修预算

“生成布局”先打开家庭需求面板，可填写人数、儿童/长者、收纳偏好、参考通路宽度及目标家具采购预算。长者选项将默认通路参考设为 900 mm。检查包括门口净空、门洞宽度、可通行区域分隔、窗前高件遮挡、参考床位与人数、已知报价超预算。

生成候选继续保留结构与锁定物品，避免占用门口参考净空；收纳优先会提高柜架靠边的摆放偏好。候选按启发式分数排序，方案比较展示检查原因和警告。儿童选项提供人工复核提醒，不自动认证家具安全；预算目前用于超支提醒，不自动替换商品；没有计算真实日照或完整规范。

预算支持启用单个或全部房间，并按各房间分别填写六种单价：地面材料/人工、墙面材料/人工、顶面材料/人工。可把当前房间报价套用到全部房间。计算依据：

- 地面、顶面面积：房间净轮廓面积。
- 墙面面积：净周长×层高，减去关联门窗面积。矮墙、坡顶、异形造型等需要人工复核，尚非完整工程计量。
- 材料数量：基础面积×（1+损耗比例）；人工数量不加损耗。
- 水电、安装等：用户添加项目、数量、单位、单价，不猜测地区市场价。
- 金额：各行按整数分舍入，再计算预留金。空单价保持待询价，不能按免费商品理解。明确显示未启用的房间未计入估算。
- CSV/PDF 使用同一预算函数，包含装修及家具项目、数量、待询价、预留金和已知预计总额；JSON 保存报价配置。

测试示例：20㎡房间，地面材料测试价 100 元/㎡、损耗 5%，人工测试价 50 元/㎡，水电补充测试项 3×150 元。已知报价 3550 元，10% 预留金 355 元，已知预计总额 3905 元，另有四种装修单价待询价。后来两件家具分别填写测试价 100/200 元后，已知预计总额为 4235 元。上述值均为虚构测试报价。
