# 别墅外观样式与楼层连接修复

本轮针对“别墅样式单一、一层与二层外看穿模且没有连接”完成修复。现有场景会使用新的结构渲染，无需重设户型。参考项目为“3D升级验收 · 别墅演示”，全部尺寸为虚构演示数据。

## 直接使用

1. 打开项目，进入“3D 空间 → 建筑外观”。
2. 在画面左下角“建筑外观样式”中选择样式；可拖动旋转检查四面、滚轮缩放，点击“重置 3D 视角”恢复取景。
3. 编辑权限下会自动保存外观选择，支持撤销/重做；刷新后仍保留。只读预览可临时切换，不写入项目。
4. “放大3D视图”可扩大画面。切换外观、剖面和漫游时保留放大状态；手机竖屏按视口比例调整俯览距离，完整显示建筑。

本机入口：[别墅演示项目](http://localhost:5180/projects/4f45f242-b02a-4e55-b1eb-8fdd57af2868)。API 与前端需保持运行；启动方式见根目录 README。

## 楼层断裂与穿模的原因及修复

原别墅一层室内墙高为 3200 mm，二层楼面标高为 3400 mm。旧楼板只覆盖房间内轮廓，厚度为 160 mm：板底到墙头还有 40 mm 空隙，墙体厚度范围及转角又缺少完整覆盖，从外部容易看见缝隙。Loft 部分下层墙还按挑空高度生成，与上层墙重叠，可能挡住上层洞口。

当前按下列方式生成：

- **统一楼板**：每层合并室内轮廓与墙体占地，再生成 200 mm 结构板。别墅二层板底位于 3200 mm，与一层墙头连续；墙厚、转角和交接位置都有实体覆盖。房间面层仍独立支持更换铺装。
- **保留真实洞口**：楼梯井及通向该层的梯段继续布尔裁切，庭院不并入室内板；上层挑空不会被整块楼板封死。
- **重叠墙分段**：沿共线墙的实际重叠长度裁切下层墙，保留未重叠的挑空段；同一高度规则用于 3D 实体和漫游碰撞，避免隐藏的一层墙挡住二层门洞。
- **补足连接与收口**：存在真实竖向间隙时，在上层覆盖范围内补齐墙头；外部增加楼层边带、转角收口和屋檐实体，屋面与檐板连续衔接。
- **封闭退台屋面**：下层伸出上层轮廓的室内部位单独封顶，修复别墅背面退台缺口；庭院保持露天。
- **覆盖挑空空间**：主屋面合并所有到达同一屋顶高度的空间，包括 Loft 二层未覆盖的挑空客厅；山墙与凹口侧面同步封闭。

这些变化由渲染计算产生；结构尺寸、房间轮廓、门窗位置和家具布局仍使用原场景数据。外观切换不要求重新确认尺寸。本轮没有数据库迁移，也未调用收费 AI 服务。

## 开发入口与范围

| 文件 | 职责 |
| --- | --- |
| `apps/web/src/exteriorStyles.ts` | 四套外观参数及默认样式 |
| `components/visuals/buildingEnvelope.ts` | 建筑占地、统一板裁切、重叠墙高度、层间补齐、外墙筛选 |
| `components/visuals/FloorStructure3D.tsx` | 结构楼板与连接填充 |
| `components/visuals/roofGeometry.ts` | 真实轮廓的平顶/双坡/四坡屋面、山墙与退台封顶 |
| `components/visuals/Exterior3D.tsx` | 立面、檐口、门廊与屋顶材质 |
| `components/visuals/Architecture3D.tsx` | 墙洞实体、面层与结构集成 |
| `components/visuals/walkMath.ts`、`multiWalk.ts` | 与实体一致的跨层碰撞高度 |
| `components/Scene3D.tsx`、`Workspace.tsx` | 样式入口、自动保存和响应式取景（均相对 `apps/web/src/`） |
| `packages/scene/scene.schema.json` | 外观字段校验 |

以上 `components/`、`pages/` 路径均相对于 `apps/web/src/`。这是可编辑的建筑概念预览：四套样式共用用户当前户型，未新增四套不同的室内平面布局。屋面采用程序几何与程序纹理；任意复杂屋脊、排水节点、真实工程构造和照片级扫描重建仍需后续深化。现有最多两层及直跑楼梯的支持范围保持不变。
