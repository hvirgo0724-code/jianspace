日期：2026-10-23。项目：`d:\web_002\web\jianspace`。本轮聚焦 AI 结构一致性保护，以及正常页面的生成、复核与积分任务链。

## 1. 结构参考、相机与结果复核

### 尺寸来源

确认对话框区分“用户实测”和“虚构演示”。必须分别勾选相应声明，服务端把 `confirmation.basis` 冻结在几何版本中；已确认的同一版本不能直接切换来源。项目卡片、侧栏、生成面板、平面参考、结果复核和 PDF 均保留演示标识。

旧数据缺少来源字段时不会推断成用户实测。正常真实房屋流程仍需由用户填写并确认实际测量数据。模板及本轮测试数据没有冒充实测。

### 从 3D 取得同视角参考

在“空间设计 → 3D 空间 → 房间视角”或暂停后的“步行漫游”中，点击“以此视角装修”。系统保存纯场景画布的 JPEG，并携带房间/楼层、毫米相机位置、朝向、视场角、宽高比、结构哈希和家具布局哈希。参考名称固定注明“3D场景视角参考（非实拍）”。保存后打开正常 AI 生成面板。

服务端检查权限、草稿修订、场景合法性、相机范围、JPEG、当前结构与家具布局。旧截图不符合当前场景时，在预留积分及调用服务商前返回 `STALE_SCENE_REFERENCE`，要求重新取景。捕获不是对真实房屋的拍摄或测量。

每次选择最多两张本房间参考，另附一张尺寸平面，总图像数最多三张。选择顺序被保留，最后一张为视角底图；仅最后一张 3D 参考提供本次相机约束。

### 生成约束

尺寸平面携带房间形状、宽/深/高、门窗、家具；完整几何快照留存在结果元数据中。文字提示优先保留相机、墙角、开口和家具，只调整表面材质与照明；零门/零窗房间使用明确的禁止新增提示及负向约束。

结构提示总预算保守限制为 1200 UTF-8 字节，避免复杂房间或长说明挤掉关键指令。前端显示本房间的补充要求字节上限，超出时提示修改；后端再次校验，超长返回 `AI_PROMPT_TOO_LONG`，不冻结积分。不会悄悄截断用户要求。

当前服务商接口使用参考图和文字引导，没有接入经过验证的硬深度/边缘几何控制。效果图不会反写原始场景，尺寸可信来源仍是毫米场景与测量资料。

### 一次视觉检查与人工复核

启用 `AI_STRUCTURE_REVIEW_ENABLED=true` 后，图片归一化成功时最多请求一次 `DASHSCOPE_VISION_MODEL`（默认 `qwen3-vl-plus`），对照平面、来源图与结果，返回墙、门、窗、拍摄视角、家具和比例六项判断与依据。

- 明确差异保留为 `needs_revision`，页面显示“待调整”。
- 已知零开口而视觉模型报告可见新增开口时，记录高风险；可见数量小于全屋数量不直接推断为缺失。
- 视角不同会将不能可靠对照的位置项目降为“不确定”，避免把透视投影差当作结构移动。
- 单张图不能验证毫米尺寸，比例不能自动认证为一致。
- 失败、跳过、非法 JSON、空依据或信息不足都保持待人工核对；不会自动重试视觉模型或重新生图。
- 自动意见与五项人工意见分别保存。人工全选一致也不能消除已记录的自动高风险。
- 页面摘要根据逐项结果整理，模型原始说明保留在展开区并标明可能不准确；避免模型自由摘要与逐项“不确定”冲突。

“根据差异重新调整”重新打开确认面板，按原顺序选回原始参考与房间，填写最多 200 UTF-8 字节的差异摘要。不会把上一张 AI 结果当成真实来源，也不会直接发起收费请求。下一次提交是一项新任务。

## 2. 任务、积分与异常处理

| 情况 | 当前行为 |
| --- | --- |
| 正常提交 | 本地锁防止连点；提交参数生成指纹及持久会话幂等键，后端原子创建任务及预留账本 |
| 提交响应丢失 | 保留同一请求的幂等键，重放返回原任务的当前状态；不重复预留或发起第二个任务 |
| 配置/参考/说明无效 | 在任务及积分预留前校验并返回可修正错误 |
| 正常完成 | 同一事务发布结果并结算一次应用积分，页面刷新图片及余额 |
| 排队取消 | 立即终止并释放应用预留积分，不调用模型 |
| 运行中取消 | 请求取消；服务商返回后丢弃结果、释放应用积分，不能保证撤销已接受的外部用量 |
| 超时/中断 | 标记结果或账单可能不确定，不自动重复生图；提示核对百炼记录 |
| 明确额度耗尽/限流 | 依次尝试最多两个同地域备用，成功停止，一次任务只结算一次应用积分 |
| 鉴权/欠费/权限/内容拒绝/5xx/模糊超时 | 不盲切换、不自动重生图，保留可审阅错误 |
| 结果写入失败 | 回滚发布并释放应用积分；保留实际模型和已返回结果的信息，提示服务商可能已产生用量 |
| 取消或租约恢复后旧 worker 晚到 | 按任务尝试号、租约和原子终态更新保护，不覆盖终态、不发布已取消结果、不二次结算 |

外部生图及布局计算在数据库事务之外执行。短事务领取、心跳续租和比较更新，保证外部调用期间取消接口仍可用。租约过期归还应用积分时，无法保证外部服务商没有完成；晚到结果不自动归档为成功。

本地/对象存储写入先验证数据库元数据可写，写入中途异常执行尽力清理。数据库提交与对象存储不是分布式事务，最终提交失败或清理失败仍可能留下孤立文件，不能宣称所有异常下完全无残留；生产需要定期清理、监控和恢复演练。

应用积分与百炼账单是两套记录。可选视觉检查计入当前一次任务的应用积分上限，服务商仍分别计量图像请求与视觉 token。余额页面和任务记录不会声称可以读取服务商剩余额度或保证免费。
